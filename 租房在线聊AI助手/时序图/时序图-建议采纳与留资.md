# 建议采纳与留资完整流程

```mermaid
sequenceDiagram
    box C端
        participant 客户
    end
    box 业务后端
        participant 在线聊平台
    end
    box AI后端
        participant AI助手
    end
    box B端
        participant 经纪人客户端
        actor 经纪人
    end

    Note over 客户,经纪人: === 客户发消息，触发AI生成建议 ===

    客户->>在线聊平台: 发送消息<br/>"可以，明天下午能看吗"
    在线聊平台->>AI助手: 推送消息


    AI助手->>经纪人客户端: 推送建议卡片

    Note over 经纪人客户端: ┌─────────────────┐<br/>│ 建议正文：<br/>│ 好的，明天下午可以看。<br/>│ 您留个电话，我约业主时间联系您<br/>│<br/>│ 📋 建议同时发送留资卡片<br/>│<br/>│ [复制] [使用] [忽略]<br/>│ 触发原因：客户有约看意向<br/>└─────────────────┘

    经纪人客户端-->>经纪人: 看到建议卡片

    Note over 客户,经纪人: === 经纪人采纳建议，编辑后发送 ===

    经纪人->>经纪人客户端: 点击"复制"（填入输入框）

    Note over 经纪人: 经纪人编辑文案（小幅修改）

    经纪人->>经纪人客户端: 点击发送
    经纪人客户端->>在线聊平台: 发送文案<br/>"好的，明天下午可以看。<br/>您留个电话，我约业主时间联系您"
    经纪人客户端->>经纪人:确认是否发送留资卡片
    经纪人->>经纪人客户端:确认发送留资卡片
    经纪人客户端->>在线聊平台: 发送留资卡片


    在线聊平台->>客户: 推送文案
    在线聊平台->>客户: 推送留资卡片
    Note over 客户: 客户看到文案 + 留资卡片<br/>┌──────────────────┐<br/>│ 好的，明天下午可以看。<br/>│ 您留个电话，我约业主时间联系您<br/>│<br/>│ 📋 留资卡片<br/>│ [确认发送手机号]<br/>└──────────────────┘
    客户->>在线聊平台: 点击同意，发送手机号
    在线聊平台->>经纪人客户端: 消息透传
