# 租赁客户难度等级划分规则

## 概述

规则基于 7160 条租赁会话画像统计结果，以会话轮次为基准划分四个难度等级，并结合各轮次内客户画像特征分布设定模拟客户的行为参数。

**核心原则：**
1. 轮次是难度划分的基准线，但不是唯一标准——同一轮次内客户画像存在分布差异，模拟时需从分布中随机采样
2. 每个维度的标签在各自轮次内有概率分布，而非固定值——模拟客户的具体特征从分布中按概率抽取
3. 各难度等级的画像特征存在重叠区间——低难度可能偶现高难度特征，高难度也可能有简单片段，模拟时需保留这种不确定性
4. 目标是训练经纪人的沟通技巧，而非让经纪人找到"标准答案"——模拟客户的行为应具有合理的变化空间，避免模式化

> 租赁交易金额相对较小、决策周期短，整体难度系数基准偏低，但客户对付款方式、租期等条款敏感度较高。

## 难度等级定义

### LEVEL 1 — 入门（会话轮数为1-2 轮）

**轮次特征统计（n=1870）：**

| 维度 | Top3 标签 | 占比特征 |
|------|-----------|----------|
| 性格特征 | 果断型(440) > 分析型(387) > 谨慎型(38) | 果断型和分析型主导，谨慎型极少 |
| 租赁目的 | 不确定(557) > 合租需求(84) > 长期居住(42) | 目的不明确为主 |
| 决策模式 | 快速决策(453) > 被动型(372) > 比较型(16) | 快速决策与被动型并存 |
| 价格敏感度 | 中敏感度(325) > 低敏感度(73) > 高敏感度(18) | 中低敏感度为主 |
| 意向阶段 | 咨询阶段(1517) > 浏览阶段(159) > 约看阶段(103) | 咨询阶段绝对主导 |
| 沟通风格 | 积极主动(1701) > 选择性开放(1254) > 信息开放(525) | 积极但信息选择性开放 |
| 核心需求 | 预算(1145) > 租赁类型(1138) > 面积(1117) | 基础需求为主 |

**画像特征逻辑：**
- 对话轮次少意味着客户决策路径短，或经纪人引导效率高
- 果断型占比高说明客户倾向快速表态，被动型占比也高说明部分客户依赖经纪人推荐
- 租赁目的不确定占比最高，说明很多客户尚未明确需求，需要经纪人帮助梳理
- 核心需求集中在预算、租赁类型、面积三个基础维度，需求层次较浅

**模拟客户行为参数：**

| 行为维度 | 参数设定 | 变化空间 |
|----------|----------|----------|
| 对话轮次 | 1-2 轮 | 固定范围 |
| 性格抽取 | 果断型(40%) / 分析型(35%) / 被动型(15%) / 其他(10%) | 可调整概率 |
| 目的明确度 | 不确定(60%) / 合租(15%) / 长期居住(15%) / 短期过渡(10%) | 可调整概率 |
| 决策速度 | 快速决策(55%) / 被动型(35%) / 其他(10%) | 可调整概率 |
| 价格敏感度 | 中(70%) / 低(20%) / 高(10%) | 可调整概率 |
| 信息开放度 | 选择性开放(60%) / 信息开放(30%) / 信息保守(10%) | 可调整概率 |
| 需求复杂度 | 基础需求 2-3 个（预算+租赁类型+面积） | 需求数量 ±1 |
| 留资意愿基线 | 35% | 可调整概率 |
| 留资满意度阈值 | 60 分 | 可调整阈值 |
| 拒绝满意度阈值 | 20 分 | 可调整阈值 |
| 最大不匹配次数 | 4 次 | 可调整次数 |

**行为模式示例（非标准答案，仅供理解）：**
- 场景A（果断型+快速决策）：客户直接询问"XX区有没有一居室，预算3000"，经纪人推荐后客户快速回复"可以，约个时间看看"——经纪人需快速匹配需求
- 场景B（被动型+目的不确定）：客户只发了一句"想租房"，后续全靠经纪人追问——经纪人需主动梳理客户需求
- 场景C（分析型+选择性开放）：客户提问精确但不愿透露预算——经纪人需通过房源信息引导客户表态

> **反模式化设计：** 即使是入门级，也有 10% 概率出现高敏感度或信息保守的特征，模拟"看似简单但有隐藏门槛"的客户。培训系统不应让经纪人形成"轮次少=好搞定"的固定认知。

### LEVEL 2 — 中等（会话轮数为3-10 轮）

**轮次特征统计（n=1953）：**

| 维度 | Top3 标签 | 占比特征 |
|------|-----------|----------|
| 性格特征 | 分析型(1082) > 果断型(826) > 谨慎型(417) | 分析型上升，果断型下降，谨慎型出现 |
| 租赁目的 | 不确定(934) > 长期居住(330) > 合租需求(237) | 不确定仍高，但长期居住明显增加 |
| 决策模式 | 快速决策(760) > 被动型(486) > 比较型(435) | 三种模式更均衡 |
| 价格敏感度 | 中敏感度(478) > 高敏感度(204) > 低敏感度(171) | 高敏感度开始出现 |
| 意向阶段 | 咨询阶段(1449) > 约看阶段(381) > 准备签约(88) | 咨询为主，约看增加 |
| 沟通风格 | 积极主动(1856) > 选择性开放(1051) > 信息开放(881) | 信息开放度提升 |
| 核心需求 | 租赁类型(1070) > 户型(1038) > 预算(1001) | 需求细化，户型关注增加 |

**画像特征逻辑：**
- 对话轮次增加意味着客户需要更多信息才能决策，分析型性格占比上升是自然结果
- 谨慎型出现说明部分客户开始犹豫，需要经纪人提供更多依据
- 决策模式三种类型更均衡，说明客户群体的决策路径出现分化
- 高敏感度开始出现，价格成为部分客户的关注点
- 核心需求从基础三件套扩展到户型，说明客户开始关注房源细节

**模拟客户行为参数：**

| 行为维度 | 参数设定 | 变化空间 |
|----------|----------|----------|
| 对话轮次 | 3-10 轮 | 固定范围 |
| 性格抽取 | 分析型(40%) / 果断型(30%) / 谨慎型(20%) / 其他(10%) | 可调整概率 |
| 目的明确度 | 不确定(50%) / 长期居住(25%) / 合租(15%) / 其他(10%) | 可调整概率 |
| 决策速度 | 快速决策(35%) / 被动型(25%) / 比较型(25%) / 其他(15%) | 可调整概率 |
| 价格敏感度 | 中(55%) / 高(20%) / 低(25%) | 可调整概率 |
| 信息开放度 | 选择性开放(45%) / 信息开放(40%) / 信息保守(15%) | 可调整概率 |
| 需求复杂度 | 中等需求 3-4 个（预算+租赁类型+户型+面积/地段） | 需求数量 ±1 |
| 犹豫行为 | 15% 概率在某个需求上反复确认 | 概率可调 |
| 留资意愿基线 | 25% | 可调整概率 |
| 留资满意度阈值 | 65 分 | 可调整阈值 |
| 拒绝满意度阈值 | 25 分 | 可调整阈值 |
| 最大不匹配次数 | 4 次 | 可调整次数 |

**行为模式示例：**
- 场景A（分析型+比较型）：客户连续询问多个房源的价格、户型、面积，对比后犹豫不决——经纪人需提供差异化推荐
- 场景B（果断型+快速决策+高敏感度）：客户快速选中房源但对价格不满——经纪人需在价格和服务之间找平衡
- 场景C（被动型+目的不确定+信息保守）：客户不主动说需求，经纪人多轮引导后才透露——经纪人需耐心挖掘

> **反模式化设计：** 中等级别引入 20% 高敏感度概率，但高敏感度客户的议价方式不固定——有的直接砍价、有的委婉比较、有的用竞品施压。模拟系统应从多种议价策略中随机选择，避免经纪人形成固定应对套路。

### LEVEL 3 — 中高（会话轮数为10-20 轮）

**轮次特征统计（n=1969）：**

| 维度 | Top3 标签 | 占比特征 |
|------|-----------|----------|
| 性格特征 | 分析型(1782) > 谨慎型(1237) > 果断型(667) | 分析型+谨慎型主导，果断型大幅下降 |
| 租赁目的 | 长期居住(1144) > 不确定(375) > 合租需求(254) | 目的明确化，长期居住反超 |
| 决策模式 | 比较型(1407) > 快速决策(364) > 价格驱动(359) | 比较型主导，价格驱动出现 |
| 价格敏感度 | 中敏感度(784) > 高敏感度(767) > 低敏感度(78) | 中高敏感度接近 1:1，低敏感度极少 |
| 意向阶段 | 咨询阶段(1170) > 约看阶段(719) > 准备签约(79) | 约看阶段占比明显增加 |
| 沟通风格 | 积极主动(1963) > 信息开放(1166) > 选择性开放(785) | 信息开放度进一步提升 |
| 核心需求 | 预算(1309) > 户型(1046) > 租赁类型(1004) | 需求更复杂 |

**画像特征逻辑：**
- 10+ 轮对话说明客户需求更复杂或决策更谨慎，分析型和谨慎型主导是必然结果
- 租赁目的从不确定转向长期居住，说明客户群体更成熟，需求更明确
- 比较型决策模式主导说明客户会对比多个房源，对经纪人的专业度要求更高
- 高敏感度占比接近中敏感度，价格成为核心博弈点
- 约看阶段占比增加说明客户从线上咨询进入线下行动，转化窗口打开
- 信息开放度提升说明客户愿意分享更多信息以获得更精准的推荐

**模拟客户行为参数：**

| 行为维度 | 参数设定 | 变化空间 |
|----------|----------|----------|
| 对话轮次 | 10-20 轮 | 固定范围 |
| 性格抽取 | 分析型(45%) / 谨慎型(30%) / 果断型(15%) / 其他(10%) | 可调整概率 |
| 目的明确度 | 长期居住(55%) / 不确定(20%) / 合租(15%) / 其他(10%) | 可调整概率 |
| 决策速度 | 比较型(55%) / 价格驱动(15%) / 快速决策(15%) / 其他(15%) | 可调整概率 |
| 价格敏感度 | 中(45%) / 高(45%) / 低(10%) | 可调整概率 |
| 信息开放度 | 信息开放(50%) / 选择性开放(35%) / 信息保守(15%) | 可调整概率 |
| 需求复杂度 | 复杂需求 4-5 个（预算+户型+租赁类型+面积+地段/交通/装修） | 需求数量 ±1 |
| 比较行为 | 40% 概率同时关注 2-3 个房源 | 概率可调 |
| 议价行为 | 30% 概率主动议价或对比价格 | 概率可调 |
| 留资意愿基线 | 20% | 可调整概率 |
| 留资满意度阈值 | 70 分 | 可调整阈值 |
| 拒绝满意度阈值 | 30 分 | 可调整阈值 |
| 最大不匹配次数 | 3 次 | 可调整次数 |

**行为模式示例：**
- 场景A（分析型+比较型+高敏感度）：客户详细对比 3 个房源的价格、户型、地段，反复计算性价比——经纪人需提供专业分析和差异化推荐
- 场景B（谨慎型+比较型+中敏感度）：客户对每个细节都反复确认，犹豫不决——经纪人需建立信任并提供决策依据
- 场景C（分析型+价格驱动+信息开放）：客户明确告知需求但坚持议价——经纪人需在价格和服务价值之间找到平衡点

> **反模式化设计：** 中高级别的客户虽然分析型和谨慎型主导，但仍有 15% 果断型概率——这类"高轮次但果断"的客户可能在某个关键点上突然决策，也可能因为某个细节突然放弃。模拟系统应设置"触发点"机制：某个特定条件满足时（如价格低于预期、房源匹配核心需求），客户行为会突然转变。经纪人需要识别这些触发点而非按固定流程应对。

### LEVEL 4 — 高等（会话轮数为21 轮及以上）

**轮次特征统计（n=1368）：**

| 维度 | Top3 标签 | 占比特征 |
|------|-----------|----------|
| 性格特征 | 分析型(1299) > 谨慎型(1140) > 果断型(332) | 分析型+谨慎型绝对主导，果断型极少 |
| 租赁目的 | 长期居住(1046) > 短期过渡(145) > 合租需求(120) | 长期居住绝对主导 |
| 决策模式 | 比较型(1203) > 价格驱动(440) > 谨慎延迟(274) | 比较型+价格驱动主导 |
| 价格敏感度 | 高敏感度(776) > 中敏感度(461) > 低敏感度(21) | 高敏感度反超，低敏感度几乎消失 |
| 意向阶段 | 约看阶段(677) > 咨询阶段(630) > 准备签约(56) | 约看阶段首次超过咨询 |
| 沟通风格 | 积极主动(1367) > 信息开放(753) > 选择性开放(600) | 沟通深入但选择性开放回升 |
| 核心需求 | 预算(1046) > 户型(810) > 地段(777) | 地段关注显著增加，需求精细 |

**画像特征逻辑：**
- 21+ 轮对话说明客户需求高度复杂或决策极度谨慎，分析型和谨慎型几乎垄断
- 长期居住目的绝对主导说明客户对房源要求更高，不会轻易妥协
- 比较型+价格驱动组合说明客户既要比房源又要比价格，对经纪人综合能力要求极高
- 高敏感度反超中敏感度，价格博弈成为核心难点
- 约看阶段首次超过咨询阶段，说明高轮次客户已经进入深度决策阶段，但迟迟未签约
- 地段关注显著增加说明客户需求从基础参数转向区位价值，对经纪人区域知识要求更高
- 选择性开放回升说明虽然整体沟通积极，但客户在关键决策信息上更加谨慎

**模拟客户行为参数：**

| 行为维度 | 参数设定 | 变化空间 |
|----------|----------|----------|
| 对话轮次 | 21+ 轮 | 下限固定，上不限 |
| 性格抽取 | 分析型(45%) / 谨慎型(35%) / 果断型(10%) / 其他(10%) | 可调整概率 |
| 目的明确度 | 长期居住(70%) / 短期过渡(10%) / 合租(10%) / 其他(10%) | 可调整概率 |
| 决策速度 | 比较型(45%) / 价格驱动(25%) / 谨慎延迟(15%) / 其他(15%) | 可调整概率 |
| 价格敏感度 | 高(55%) / 中(35%) / 低(10%) | 可调整概率 |
| 信息开放度 | 信息开放(45%) / 选择性开放(35%) / 信息保守(20%) | 可调整概率 |
| 需求复杂度 | 精细需求 5+ 个（预算+户型+地段+面积+交通+装修/朝向/楼层等） | 需求数量 ±1-2 |
| 多房源对比 | 50% 概率同时关注 3+ 个房源 | 概率可调 |
| 议价行为 | 40% 概率主动议价，20% 概率用竞品施压 | 概率可调 |
| 犹豫转折 | 25% 概率在约看后突然提出新需求或改变条件 | 概率可调 |
| 留资意愿基线 | 15% | 可调整概率 |
| 留资满意度阈值 | 75 分 | 可调整阈值 |
| 拒绝满意度阈值 | 35 分 | 可调整阈值 |
| 最大不匹配次数 | 3 次 | 可调整次数 |

**行为模式示例：**
- 场景A（分析型+比较型+高敏感度）：客户用 20+ 轮对比 5 个房源的价格、户型、地段、交通，反复计算性价比，最终因 200 元差价选择竞品——经纪人需在早期建立差异化优势
- 场景B（谨慎型+谨慎延迟+选择性开放）：客户对每个条件都反复确认，约看后又提出新的修改要求——经纪人需管理客户预期并提供灵活方案
- 场景C（分析型+价格驱动+信息开放）：客户明确告知所有需求但坚持大幅议价，用竞品价格施压——经纪人需展示服务价值而非单纯价格竞争

> **反模式化设计：** 高等难度的核心挑战不在于客户"难搞"，而在于客户"专业"——他们信息充分、逻辑清晰、有明确的议价策略。但仍有 10% 果断型概率，这类客户会在长期比较后突然决策，且决策依据可能出乎意料（如对经纪人服务态度的认可）。模拟系统应设置"隐藏决策因子"：客户在多轮沟通中会积累对经纪人的"信任值"和"专业值"，当某个因子达到阈值时可能触发意外决策。经纪人无法通过固定话术达成留资，必须真正理解客户需求并提供差异化价值。

|------|-----------|------------|-------------|-----------|----------|
| 分析型占比 | 35% | 40% | 45% | 45% | 逐级上升，中高后趋稳 |
| 谨慎型占比 | 3% | 15% | 30% | 35% | 持续上升，高等达峰 |
| 果断型占比 | 40% | 30% | 15% | 10% | 持续下降 |

| 地段需求占比 | 低 | 低 | 中 | 高 | 高等阶段显著增加 |

### 留资转化窗口

| 轮次区间 | 咨询→约看转化难点 | 约看→签约转化难点 |
|----------|-------------------|-------------------|
| 1-2 轮 | 客户目的不明确，需快速梳理 | 转化快，但可能因信息不足反悔 |
| 3-10 轮 | 需求细化但比较型增加，需差异化推荐 | 价格博弈开始出现 |
| 10-20 轮 | 比较型主导，需提供专业分析 | 高敏感度客户需价格谈判技巧 |
| 21+ 轮 | 已过约看阶段，核心是信任建立 | 长期犹豫，需管理预期+灵活方案 |

## 模拟客户生成规则

### 随机采样机制

模拟客户的画像特征不是固定的，而是从对应难度等级的概率分布中随机采样：

```
生成流程：
1. 根据难度等级确定轮次范围
2. 从性格分布中按概率抽取 1-2 个性格标签
3. 从租赁目的分布中按概率抽取 1 个目的标签
4. 从决策模式分布中按概率抽取 1 个决策标签
5. 从价格敏感度分布中按概率抽取 1 个敏感度标签
6. 从意向阶段分布中按概率抽取 1 个阶段标签
7. 从沟通风格分布中按概率抽取 2 个风格标签（活跃度+开放度）
8. 从核心需求池中按概率抽取 2-5 个需求标签
9. 根据抽取结果生成具体的对话策略和行为参数
```

### 行为变异机制

为防止模式化，每个难度等级设置以下变异机制：

| 变异类型 | 触发概率 | 效果 |
|----------|----------|------|
| 特征越级 | 10-15% | 低难度出现高难度特征（如入门级出现高敏感度） |
| 行为突变 | 15-25% | 对话中途改变行为模式（如果断型突然变犹豫） |
| 隐藏需求 | 20-30% | 初始未表达的需求在特定条件下触发 |
| 触发点响应 | 视情况 | 满足特定条件时行为发生质变 |

### 对话策略动态生成

模拟客户的对话策略不是预设的固定话术，而是基于抽取的画像特征动态生成：

| 画像维度 | 影响的对话行为 |
|----------|----------------|
| 性格特征 | 回复长度、语气、情绪波动、提问方式 |
| 租赁目的 | 关注点侧重、决策紧迫度 |
| 决策模式 | 比较行为、议价行为、犹豫行为 |
| 价格敏感度 | 价格讨论频率、议价幅度、价格谈判策略 |
| 意向阶段 | 行动意愿、看房安排、签约推进 |
| 沟通风格 | 信息透露程度、主动提问频率、回复速度 |
| 核心需求 | 需求表达方式、条件刚性程度、妥协空间 |

### 结构化输出与 action 决策

模拟客户对经纪人的每条消息必须输出结构化 JSON，包含 `response`（回复内容）、`action`（行为动作：chat/leave_phone/refuse）、`action_reason`（决策理由）。

action 决策基于以下参数：

| 参数 | 说明 | 入门 | 中等 | 中高 | 高等 |
|------|------|------|------|------|------|
| leave_phone_baseline | 留资意愿基线 | 35% | 20% | 12% | 5% |
| leave_phone_satisfaction_threshold | 留资满意度阈值 | 55分 | 65分 | 75分 | 85分 |
| refuse_threshold | 拒绝满意度阈值 | 15分 | 20分 | 25分 | 30分 |
| max_mismatch_count | 最大不匹配次数 | 5次 | 4次 | 3次 | 2次 |
| leave_phone_triggers | 留资触发条件数 | 3条 | 4条 | 5条 | 6条 |
| refuse_triggers | 拒绝触发条件数 | 2条 | 3条 | 5条 | 8条 |

决策逻辑：
1. 评价经纪人消息 → 计算综合满意度（0-100）
2. 检查是否命中拒绝触发条件 → 命中则直接 refuse
3. 检查不匹配次数 → 超过 max_mismatch_count 则 refuse
4. 检查满意度是否低于拒绝阈值 → 低于则 refuse
5. 检查是否命中留资触发条件 + 满意度 ≥ 留资阈值 → 可考虑 leave_phone
6. 否则继续 chat

**梯度设计逻辑：**
- 留资意愿基线从 35% 降至 5%：高难度客户几乎不会主动留资，必须被经纪人"打动"
- 留资满意度阈值从 55 升至 85：高难度客户需要经纪人表现极好才考虑留资
- 拒绝满意度阈值从 15 升至 30：高难度客户容忍度更低，但不会因小失误就离开
- 最大不匹配次数从 5 降至 2：高难度客户不会给经纪人太多试错机会
- 留资触发条件从 3 条增至 6 条：高难度客户需要经纪人做到更多具体行为才愿意留资
- 拒绝触发条件从 2 条增至 8 条：高难度客户有更多"一票否决"的场景

## 使用场景

### 经纪人培训难度匹配

| 经纪人等级 | 推荐难度 | 训练目标 |
|------------|----------|----------|
| 新人（0-3个月） | 入门 | 基础需求梳理、快速匹配、信息收集 |
| 初级（3-6个月） | 中等 | 需求细化、差异化推荐、初步议价 |
| 中级（6-12个月） | 中高 | 多房源对比、价格谈判、专业分析 |
| 高级（12个月+） | 高等 | 信任建立、预期管理、复杂博弈 |

### 对练平台集成

模拟客户系统读取本规则后：
1. 经纪人选择难度等级
2. 按概率分布随机生成客户画像
3. 应用变异机制增加不可预测性
4. 根据画像特征动态生成对话策略
5. 记录经纪人的应对表现，用于评估和复盘

## 扩展与调整

| 调整项 | 方法 | 影响 |
