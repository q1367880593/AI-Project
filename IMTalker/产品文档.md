# 爱聊对练（IMTalker）— 产品文档

## 一、产品定位

**爱聊对练** 是一款面向租房经纪人的 AI 对话训练工具。通过 AI 模拟真实客户，为经纪人提供 7×24 小时、标准化、可量化的沉浸式对话训练体验。

**一句话定位：** 让每位经纪人都能随时随地进行客户沟通实战演练，不再依赖真人角色扮演。

---

## 二、背景与痛点

### 2.1 行业现状

租房经纪行业高度依赖经纪人的沟通能力。一个经纪人每天需要面对数十位客户，客户画像千差万别——有的预算敏感、有的防备心强、有的急租、有的挑剔。能否在短时间内理解客户需求、建立信任、推进成交，直接决定了经纪人的业绩。

### 2.2 传统培训的痛点

| 痛点 | 具体表现 |
|------|----------|
| **培训成本高** | 需要培训师 + 经纪人双方时间，一次陪练至少 30 分钟 |
| **覆盖面窄** | 只能练习有限几种客户类型，无法覆盖真实场景的多样性 |
| **标准不统一** | 不同培训师的评判标准不同，无法量化评估 |
| **频率不足** | 新人训练频次低，无法形成肌肉记忆 |
| **缺乏反馈** | 练完就结束，没有实时诊断和改进建议 |
| **心理压力** | 新人面对真人培训师容易紧张，不敢试错 |

### 2.3 核心矛盾

**经纪人的沟通能力只能在实战中提升，但实战中犯错代价太高**——一个错误的回复可能导致客户流失。AI 陪练提供了一个"零成本犯错"的安全环境。

## 三、目标用户

| 用户角色 | 核心诉求 | 使用场景 |
|----------|----------|----------|
| **新人经纪人** | 快速上手，学习标准话术，建立信心 | 入职培训、每日练习 |
| **在职经纪人** | 挑战高难度客户，提升转化率 | 针对性训练、薄弱环节补强 |
| **培训师/管理者** | 标准化培训流程，量化评估效果 | 批量培训、考核验收 |

---

## 四、产品目标

### 4.1 核心目标

**让经纪人在 10 分钟内完成一次高质量的客户对话训练，并获得即时反馈。**

### 4.2 量化指标

| 维度 | 目标 |
|------|------|
| 单次训练时长 | ≤ 10 分钟 |
| 客户画像覆盖 | 覆盖 4 个难度级别（入门/中等/中高/高等），不限数量，随机生成 |
| 反馈时效 | 对话结束后即时输出诊断报告 |
| 上手门槛 | 无需安装，浏览器打开即用 |

### 4.3 阶段目标

- **Phase 1（已完成）** — 客户模拟 Agent：AI 扮演客户，经纪人自由对话练习
- **Phase 2** — 状态跟踪 + 实时复盘：对话中实时显示客户状态变化和诊断建议
- **Phase 3** — 训练闯关模式：按难度递进，完成关卡才能解锁下一关
- **Phase 4** — 数据看板：训练数据统计、个人进步曲线、团队排名

## 五、产品价值

### 5.1 对经纪人

- **零成本试错** — 跟 AI 客户对话，说错了不会丢客户，可以反复练习
- **多样客户覆盖** — 从随和到挑剔，从预算敏感到防备心强，提前适应各种客户类型
- **即时反馈** — 每条回复都有客户状态标签（聊天/留资/拒绝），知道哪句话说对了、哪句话说错了
- **真实参考** — 每条客户画像都附带真实对话记录，可以学习优秀话术

### 5.2 对企业/培训方

- **降本增效** — 1 个培训师可以同时管理 N 个 AI 陪练，培训成本大幅降低
- **标准化** — 所有经纪人基于同一套标准训练，考核结果可量化对比
- **可扩展** — 画像由生成脚本自动产出，无需人工配置，新客户类型零成本扩展
- **数据驱动** — 训练数据沉淀为团队能力画像，识别薄弱环节

### 5.3 差异化优势

| 对比维度 | 传统角色扮演 | 话术文档 | 爱聊对练 |
|----------|-------------|----------|----------|
| 可用时间 | 培训师在场时 | 随时 | 随时 |
| 覆盖客户类型 | 3-5 种 | 无交互 | **不限数量，运行时随机生成** |
| 交互反馈 | 主观评价 | 无 | 量化 + 即时 |
| 试错成本 | 高（浪费培训师时间） | 无 | 零 |
| 训练频率 | 每周 1-2 次 | — | 不限次数 |
| 真实感 | 面对面，场景感弱 | 无场景 | **还原线上爱聊完整对话体验** |

### 5.4 高度还原的真实对话体验

系统依托真实线上爱聊对话数据，**完整还原了线上爱聊的所有对话功能**，让训练场景与经纪人日常工作场景完全一致：

- **房源卡片消息** — 支持模拟线上房源推荐，接入正式房源数据，训练经纪人在真实工具环境下的推荐房源能力
- **系统消息** — 还原用户进入聊天、自动回复等系统级消息，模拟完整的线上对话上下文
- **真实对话节奏** — 对话数据来源于真实爱聊记录，保留客户的自然回复间隔、表达习惯和话题跳跃，避免 AI 对话的"机械感"
- **业务场景覆盖** — 涵盖朝向、面积、通勤时间、预算、楼层、装修等客户核心找房需求场景，每个场景都有对应的对话数据支撑

> 经纪人面对的不是一个"聊天机器人"，而是一个在真实爱聊界面中、以真实对话模式与你沟通的客户。

## 六、产品方案

### 6.1 核心机制：AI 客户模拟

AI 客户由一个完整的 **客户画像** 驱动。**画像并非预置的固定列表，而是通过画像生成脚本在运行时随机生成**，每次训练都可能遇到不同的客户，确保训练的多样性和不可预测性。

画像包含 7 个维度，每个维度在生成时从预设的取值池中随机组合：

- **性格特征**（果断型/谨慎型/分析型/挑剔型/随和型...）
- **租赁目的**（长期居住/短期过渡/不确定）
- **决策模式**（比较型/快速决策/价格驱动/被动型）
- **价格敏感度**（高/中/低）
- **意向阶段**（浏览/咨询/约看/准备签约）
- **沟通风格**（积极主动/信息开放/选择性开放/被动回应）
- **核心需求**（地段/户型/预算/装修/养宠...）

每个维度都有对应的行为参数（回复长度、妥协意愿、异议概率、留资门槛等），确保 AI 客户的行为符合画像设定。

### 6.2 难度机制

通过调整行为参数实现 4 级难度梯度：

| 维度 | 入门 | 中等 | 中高 | 高等 |
|------|------|------|------|------|
| 妥协意愿 | 70% | 50% | 35% | 20% |
| 留资门槛 | 低 | 中 | 中高 | 高 |
| 容忍不匹配 | 6 次 | 4 次 | 3 次 | 2 次 |
| 隐藏需求 | 少 | 中 | 较多 | 多 |

### 6.3 Agent 编排体系

系统采用多 Agent 协作架构，每个 Agent 专注一个职责，协同完成从"生成训练场景"到"输出训练报告"的完整闭环：

```
场景导演 Agent
      │
      ▼
客户模拟 Agent  ←→  状态跟踪 Agent
      │                  │
      ▼                  ▼
实时复盘 Agent  ←───  评分教练 Agent
```

#### 6.3.1 场景导演 Agent

**职责：** 每局训练开始前，根据难度和场景设定，生成该局的训练目标、客户隐藏顾虑和失败条件。

- 输入：客户画像 + 难度级别 + 场景类型 + **经纪人作业范围**
- 处理：
  - 从**真实线上房源库**中，按经纪人作业范围拉取真实房源信息
  - 根据客户画像特征，从候选房源中选取最匹配的房源卡片（如：价格敏感型客户匹配低价房源，通勤导向型客户匹配地铁沿线房源）
- 输出：本局训练目标、隐藏顾虑列表、失败条件、**客户开场白及咨询房源卡片**
- 价值：确保训练场景基于真实房源数据，且与经纪人实际作业范围高度相关，而非虚构的"假房源"

#### 6.3.2 客户模拟 Agent（✅ Demo 完成）

**职责：** 严格按照客户画像扮演客户角色，与经纪人进行文字对话。保持画像一致性，根据经纪人回复实时调整态度。

- 输入：客户画像（7 维度 + 行为参数）+ 经纪人消息
- 输出：客户回复文本 + action 决策（聊天/留资/拒绝）+ 决策理由
- 价值：提供真实、多样、不可预测的客户交互体验

#### 6.3.3 状态跟踪 Agent

**职责：** 每轮对话后更新客户内部状态，量化经纪人的表现。

| 跟踪指标 | 说明 | 示例 |
|----------|------|------|
| 信任度 | 客户对经纪人的信任程度 | 68 → 72（因经纪人专业解答而提升） |
| 意向度 | 客户租房/留资的意愿强度 | 74 → 58（因推荐不匹配而下降） |
| 需求完整度 | 经纪人已挖掘的需求比例 | 62%（还有预算和入住时间未明确） |
| 烦躁度 | 客户的不满/不耐烦程度 | 36 → 45（因经纪人连续追问而上升） |
| 对话阶段 | 当前处于哪个沟通阶段 | 需求确认 → 匹配推荐 → 看房邀约 |

- 价值：将模糊的"聊得好不好"量化为一组可追踪的指标，让训练效果可衡量

#### 6.3.4 实时复盘 Agent

**职责：** 经纪人可随时点击复盘按钮，获取当前对话的诊断分析和改进建议。

- 输入：当前对话历史 + 客户状态数据
- 输出：
  - **当前判断** — 客户状态解读，当前阶段分析
  - **红黄线** — 红线（严重违规，如虚假承诺）/ 黄线（需注意，如过早索要电话）
  - **留资窗口分** — 当前是否适合要联系方式（0-100 分）
  - **下一步建议** — 1-2 条具体话术建议
- 价值：即时纠正错误，让经纪人在对话中学习，而非事后才发现问题

#### 6.3.5 评分教练 Agent

**职责：** 对话结束后，输出完整的评分报告和训练建议。

- 输出维度：
  - **需求挖掘**（是否充分了解客户需求）
  - **异议处理**（面对客户质疑的应对能力）
  - **推进节奏**（是否在合适时机推进留资/看房）
  - **合规表达**（是否有虚假承诺、隐私诱导等违规行为）
- 附加内容：
  - 优秀片段摘录 + 点评
  - 待改进片段 + 改进建议
  - 下一阶段训练建议
- 价值：形成训练闭环，让每次训练都有明确的学习收获

#### 6.3.6 Agent 协作流程

完整的一局训练流程，还原线上真实爱聊对话场景：

```
1. 场景导演生成训练目标 + 客户画像 + 房源卡片
2. 客户发起爱聊咨询，发送开场白及咨询房源卡片
3. 经纪人收到消息，开始回复
4. 客户模拟 Agent 生成回复 + 状态跟踪 Agent 更新状态
5. 经纪人可随时触发实时复盘 Agent 获取诊断
6. 重复步骤 4-5，直到对话结束
7. 评分教练 Agent 输出完整训练报告
```
